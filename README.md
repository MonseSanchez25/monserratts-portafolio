# Creación de portafolio profesional con Vibecoding y la herramienta de IA Lovable

Actúa como un diseñador UX/UI senior, desarrollador web y especialista en Personal Branding y reclutamiento profesional.
Quiero que diseñes y desarrolles una página web de portafolio profesional para presentar mi perfil, experiencia, competencias, certificaciones y proyectos ante reclutadores, empresas y contactos de networking.
La página debe transmitir profesionalismo, pensamiento analítico, innovación, precisión y orientación a resultados, inspirada en dashboards tecnológicos futuristas. 

Paleta de colores:
- #D90BB6
- #4E35F2
- #292259
- #0F1226
- #416EF2

Tipografías:
- Montserrat SemiBold para títulos.
- Lato Regular para textos.

Utiliza tarjetas minimalistas, líneas geométricas, gráficos estadísticos abstractos y animaciones discretas.
Evita colores excesivamente saturados y elementos visuales sobrecargados.
La página debe transmitir una personalidad profesional, analítica, organizada y accesible.


La página debe:

- Ser completamente responsive para computadoras, tablets y dispositivos móviles.
- Tener navegación sencilla y profesional.
- Incorporar animaciones suaves al desplazarse.
- Contar con excelente legibilidad y contraste.
- Tener botones funcionales y enlaces externos correctos.
- Utilizar componentes reutilizables y una estructura fácil de actualizar.
- Estar optimizada para SEO.
- Tener un diseño accesible.
- Permitir agregar proyectos nuevos en el futuro.
- Incluir un selector de idioma español/inglés si es posible, con traducciones profesionales.


5. RESULTADO ESPERADO
Genera una página web profesional, visualmente atractiva y lista para utilizar como portafolio personal.
Quiero que un reclutador pueda comprender en menos de 30 segundos:
1. Quién soy profesionalmente.
2. Qué valor puedo aportar.
3. Cuáles son mis competencias técnicas.
4. Qué experiencia y proyectos respaldan mi perfil.
5. Cómo puede contactarme.

El resultado debe parecer un portafolio de una profesional emergente en Data Analytics, Quality y Continuous Improvement, no una plantilla genérica de currículum.
